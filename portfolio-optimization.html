DATA ANALYST PROJECT

Stock Portfolio Optimization

Analisis optimasi portofolio saham menggunakan 30 saham dengan mempertimbangkan return, risiko, korelasi, Excess Return to Beta, dan Sharpe Ratio.

30 Stocks Portfolio Analysis ERB Sharpe Ratio
PROJECT

Deskripsi Singkat

Project ini melakukan analisis optimasi portofolio berdasarkan 30 saham yang digunakan sebagai universe investasi.

Analisis dilakukan dengan menghitung return saham, korelasi antar saham, Beta, Alpha, variance residual, serta Excess Return to Beta (ERB) sebagai dasar proses seleksi saham.

Setelah proses seleksi, diperoleh delapan saham yang digunakan dalam pembentukan portofolio, kemudian dievaluasi menggunakan Sharpe Ratio.

DATA

Investment Universe

INITIAL UNIVERSE 30 Stocks

Saham yang digunakan dalam analisis awal.

MARKET INDEX IHSG

Digunakan sebagai benchmark pasar.

SELECTION ERB

Excess Return to Beta.

FINAL PORTFOLIO 8 Stocks

Saham terpilih untuk pembentukan portofolio.

METHODOLOGY

Analytical Process

01 — Return Analysis

Menghitung return saham dari data harga historis masing-masing saham.

02 — Risk & Correlation

Menganalisis hubungan antar saham serta karakteristik risiko masing-masing aset.

03 — ERB Selection

Menggunakan Excess Return to Beta sebagai dasar pengurutan dan seleksi saham.

04 — Portfolio Evaluation

Mengevaluasi kombinasi saham terpilih menggunakan Sharpe Ratio.

Standard deviation of return

Berdasarkan hasil perhitungan, portofolio menghasilkan rata-rata return sebesar 0,3444% per hari. Sementara itu, tingkat risiko yang diukur menggunakan standar deviasi sebesar 1,9222%.

Nilai Sharpe Ratio sebesar 0,1718 menunjukkan bahwa setiap satu unit risiko yang ditanggung portofolio menghasilkan sekitar 0,1718 unit excess return. Dengan kata lain, Sharpe Ratio digunakan untuk melihat seberapa efisien return tambahan yang diperoleh dibandingkan dengan risiko yang ditanggung.

Nilai Sharpe yang positif menunjukkan bahwa portofolio menghasilkan excess return terhadap tingkat bebas risiko yang digunakan dalam perhitungan. Namun, berdasarkan interpretasi yang tercantum dalam analisis, nilai 0,1718 masih menunjukkan tingkat efisiensi yang relatif rendah. Artinya, masih terdapat risiko yang cukup besar dibandingkan dengan excess return yang dihasilkan portofolio.

Oleh karena itu, hasil ini menunjukkan bahwa pembentukan portofolio telah menghasilkan return positif, tetapi kombinasi return dan risiko yang diperoleh masih dapat dievaluasi lebih lanjut untuk meningkatkan efisiensi portofolio.

CONCLUSION

Kesimpulan

Analisis dimulai dengan menggunakan 30 saham sebagai universe investasi. Selanjutnya dilakukan analisis return, risiko, korelasi, Beta, Alpha, variance residual, dan Excess Return to Beta (ERB) untuk menentukan saham yang digunakan dalam pembentukan portofolio.

Berdasarkan proses seleksi tersebut, diperoleh 8 saham, yaitu ANTM, PGAS, MDKA, BRPT, ASII, TLKM, JPFA, dan EXCL. Masing-masing saham kemudian diberikan bobot berdasarkan hasil perhitungan optimasi portofolio.

Portofolio yang terbentuk menghasilkan rata-rata return sebesar 0,3444% per hari dengan tingkat risiko sebesar 1,9222%. Sementara itu, Sharpe Ratio sebesar 0,1718 menunjukkan bahwa portofolio menghasilkan sekitar 0,1718 unit excess return untuk setiap satu unit risiko yang ditanggung.

Dengan demikian, portofolio menghasilkan return positif, tetapi nilai Sharpe Ratio menunjukkan bahwa efisiensi hubungan antara return dan risiko masih relatif rendah. Hasil ini memberikan gambaran bahwa pemilihan saham dan alokasi bobot yang diperoleh dari analisis dapat menjadi dasar evaluasi lebih lanjut dalam pembentukan portofolio.
