MACHINE LEARNING PROJECT

Customer Churn Prediction

End-to-end Machine Learning project for predicting customer churn based on customer characteristics, services, contract type, tenure, and billing information.

Python Machine Learning Classification XGBoost
PROJECT

Deskripsi Singkat

Customer churn merupakan kondisi ketika pelanggan berhenti menggunakan suatu layanan. Project ini menggunakan Machine Learning untuk memprediksi apakah seorang pelanggan berpotensi mengalami churn.

Analisis dilakukan secara end-to-end mulai dari data loading, data understanding, data cleaning, Exploratory Data Analysis, feature engineering, preprocessing, model development, model evaluation, interpretasi model, hingga simulasi prediksi customer baru.

Dataset yang digunakan adalah Telco Customer Churn, yang berisi karakteristik pelanggan, informasi layanan, kontrak, lama berlangganan, dan biaya.

DATASET

Customer Data

DATASET Telco Customer Churn

Customer subscription and service data.

TARGET Churn

Yes / No customer churn status.

FEATURE TYPES Numeric + Categorical

Customer, service, contract and billing features.

PROBLEM TYPE Classification

Binary customer churn prediction.

EXPLORATORY DATA ANALYSIS

Customer Churn Patterns

Exploratory Data Analysis dilakukan untuk memahami karakteristik pelanggan dan melihat pola churn berdasarkan beberapa variabel utama.

Contract

Pelanggan dengan kontrak Month-to-month menunjukkan proporsi churn yang lebih tinggi dibandingkan kontrak lainnya.

Tenure

Pelanggan dengan lama berlangganan lebih pendek menunjukkan proporsi churn yang lebih tinggi pada dataset.

Monthly Charges

Customer yang churn memiliki rata-rata dan median MonthlyCharges yang lebih tinggi.

Internet Service

Kategori Fiber optic menunjukkan proporsi churn yang lebih tinggi dibanding kategori lainnya.

MACHINE LEARNING

Model Development

Empat algoritma klasifikasi dikembangkan dan dibandingkan untuk memprediksi customer churn.

Logistic Regression

Digunakan sebagai baseline model dan memberikan interpretasi koefisien yang lebih mudah.

Decision Tree

Model klasifikasi berbasis aturan percabangan untuk memisahkan kelas churn.

Random Forest

Ensemble model yang menggabungkan banyak Decision Tree.

XGBoost

Gradient boosting model untuk meningkatkan kemampuan klasifikasi.

PREPROCESSING

Data Preparation

Variabel TotalCharges yang awalnya terbaca sebagai object dikonversi menjadi numerik. Sebanyak 11 observasi memiliki nilai kosong dan diisi dengan 0 setelah diperiksa bahwa observasi tersebut memiliki tenure = 0.

Variabel numerik diproses menggunakan StandardScaler, sedangkan variabel kategorikal diproses menggunakan One-Hot Encoding.

Seluruh preprocessing ditempatkan dalam Pipeline bersama model untuk menjaga konsistensi transformasi antara data training dan testing.

MODEL PERFORMANCE

Model Evaluation

Accuracy

LOGISTIC REGRESSION 84.22%

ROC-AUC

CHURN RECALL 56.15%

Recall for Churn class

XGBOOST 84.62%

ROC-AUC

Model dievaluasi menggunakan Accuracy, Precision, Recall, F1-Score, dan ROC-AUC. Pada Logistic Regression, diperoleh Accuracy sebesar 80,70%, Precision kelas Churn sebesar 66,04%, Recall sebesar 56,15%, dan F1-Score sebesar 60,69%.

ROC-AUC Logistic Regression sebesar 84,22%, sedangkan XGBoost memperoleh ROC-AUC sebesar 84,62%. ROC-AUC digunakan untuk melihat kemampuan model membedakan pelanggan churn dan tidak churn pada berbagai threshold.

MODEL INTERPRETATION

Feature Interpretation

Logistic Regression digunakan untuk menginterpretasikan kontribusi fitur terhadap prediksi churn melalui koefisien model dan Odds Ratio.

Analisis interpretasi menunjukkan bahwa karakteristik seperti jenis kontrak, tenure, jenis layanan internet, dan metode pembayaran memiliki kontribusi terhadap prediksi customer churn pada model.

BUSINESS INSIGHTS

Key Insights

Hasil EDA dan pemodelan menunjukkan beberapa karakteristik yang berkaitan dengan customer churn, terutama jenis kontrak, lama berlangganan, biaya bulanan, dan jenis layanan internet.

Insight tersebut dapat digunakan sebagai informasi pendukung untuk mengidentifikasi pelanggan dengan probabilitas churn yang lebih tinggi dan membantu perancangan strategi retensi pelanggan.

CONCLUSION

Kesimpulan

Project ini berhasil membangun pipeline Machine Learning end-to-end untuk memprediksi customer churn menggunakan dataset Telco Customer Churn.

Empat algoritma klasifikasi dibandingkan, yaitu Logistic Regression, Decision Tree, Random Forest, dan XGBoost, dengan preprocessing menggunakan StandardScaler dan One-Hot Encoding.

Logistic Regression menghasilkan Accuracy sebesar 80,70% dan ROC-AUC sebesar 84,22%. XGBoost memperoleh ROC-AUC sebesar 84,62% pada pengujian yang dilakukan dalam notebook.

Project ini juga menunjukkan bagaimana hasil model dapat digunakan tidak hanya untuk melakukan prediksi, tetapi juga untuk memahami karakteristik pelanggan yang berkaitan dengan churn melalui feature interpretation dan Odds Ratio.
