DATA ANALYST PROJECT

Historical Value at Risk (VaR) Analysis — SMGR

Analisis risiko investasi saham PT Semen Indonesia (Persero) Tbk menggunakan pendekatan Historical Value at Risk berdasarkan return historis.

SMGR Historical VaR Risk Analysis Statistics
PROJECT

Deskripsi Singkat

Project ini melakukan analisis risiko investasi menggunakan metode Historical Value at Risk (VaR). Analisis dilakukan berdasarkan data harga historis dan log return untuk mengestimasi potensi kerugian investasi.

Tahapan analisis meliputi pengolahan data harga, perhitungan log return, statistik deskriptif, perhitungan Historical VaR, serta estimasi kerugian berdasarkan beberapa holding period.

DATA

Historical Price

RETURN

Log Return

METHOD

Historical VaR

Return Statistics

VALUE AT RISK

Historical VaR Result

Berdasarkan perhitungan Historical VaR pada tingkat signifikansi sebesar 5%, nilai VaR yang diperoleh adalah:

HISTORICAL VaR — α = 5% -6.1818%

Potential loss estimated from the historical return distribution.

Nilai Historical VaR sebesar -6.1818% menunjukkan estimasi potensi kerugian berdasarkan distribusi return historis pada tingkat signifikansi 5%.

INVESTMENT RISK

Estimated Investment Loss

INTERPRETATION

Risk Interpretation

01

Historical Risk

Historical VaR digunakan untuk mengukur potensi kerugian berdasarkan pola return yang terdapat pada data historis.

02

Confidence Level

Analisis menggunakan tingkat signifikansi 5%, yang setara dengan tingkat kepercayaan 95%.

03

Holding Period

Estimasi kerugian berubah ketika holding period diperpanjang dari 1 hari menjadi 5 dan 20 hari.

CONCLUSION

Kesimpulan

Analisis Historical Value at Risk memberikan ukuran kuantitatif terhadap potensi kerugian investasi berdasarkan distribusi return historis.

Pada tingkat signifikansi 5%, diperoleh Historical VaR sebesar -6.1818%. Dengan nilai investasi awal Rp1.000.000, estimasi kerugian meningkat seiring dengan holding period yang digunakan dalam analisis.
